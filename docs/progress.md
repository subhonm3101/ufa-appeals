# Журнал выполнения работы

Проект: интеллектуальная веб-система анализа и приоритизации обращений граждан с прогнозированием нагрузки (г. Уфа).

Каждый шаг фиксируется отдельным коммитом с сообщением «Шаг X.Y: …». Найти коммит шага: `git log --grep "Шаг 9.1"`.

## Измеренные показатели

- Автотесты: 163 пройдено (на 5 ноября 2026).
- Нагрузка (5242 обращения, 3509 кластеров): запросы 0,02–0,09 с, отчёт Excel 0,3 с; 10 одновременных пользователей без ошибок, около 120 запросов в секунду.
- Прогноз по городу на неделю: ошибка WAPE 10,4%, интервал 80% накрыл 78,4% фактов.
- Поиск аномалий по новым кластерам даёт примерно в 3,4 раза меньше ложных тревог, чем по числу обращений.

## Известные ограничения

- Данные синтетические, охват один год.
- Токены доступа нельзя отозвать до истечения срока (устранить на этапе 12).
- Координаты кластеров на карте группируются около центров районов.
- Прогноз по категориям не лучше простого среднего за 4 недели.
