# Журнал выполнения работы

Проект: интеллектуальная веб-система анализа и приоритизации обращений граждан с прогнозированием нагрузки (г. Уфа).

Каждый шаг фиксируется отдельным коммитом с сообщением «Шаг X.Y: …». Найти коммит шага: `git log --grep "Шаг 9.1"`.

| 11.4 | Уведомления гражданину (смена статуса, публичный ответ) и сотрудникам (гражданин дополнил обращение), миграция 0012 | выполнено |
| 11.5 | Колокольчик уведомлений в кабинете гражданина | выполнено |
| 11.6 | Внешний API приёма обращений по ключу (`X-API-Key`), ключи хранятся в виде хеша (миграция 0013) | выполнено |
| 11.7 | Вкладка «Ключи API» для администратора: выпуск, список, отзыв | выполнено |

Правила: гражданин видит только свои обращения; внутренние комментарии и данные сотрудников ему не отдаются; ответ виден после закрытия обращения; дополнять можно только открытое обращение (не более 20 сообщений в час). Внешняя система создаёт обращения с источником «api»; повтор с тем же `external_id` не создаёт дубль; ключ видит только обращения, поданные им самим; подбор ключей ограничен по адресу.

## Измеренные показатели

- Автотесты: 342 пройдено (на 11 ноября 2026).
- Нагрузка (5242 обращения, 3509 кластеров): запросы 0,02–0,09 с, отчёт Excel 0,3 с; 10 одновременных пользователей без ошибок, около 120 запросов в секунду.
- Прогноз по городу на неделю: ошибка WAPE 10,4%, интервал 80% накрыл 78,4% фактов.
- Поиск аномалий по новым кластерам даёт примерно в 3,4 раза меньше ложных тревог, чем по числу обращений.
- Э7 (порог уверенности): на тестовой выборке точность классификатора 99,0%, средняя уверенность 99,4%, при пороге 0,7 автоматически принимается 99,6% обращений. На пяти расплывчатых фразах уверенность доходила до 0,96, а доля знакомых слов не превышала 0,67 (на тестовых текстах не ниже 0,86), поэтому добавлена проверка знакомости текста.

## Известные ограничения

- Данные синтетические, охват один год.
- Токены доступа нельзя отозвать до истечения срока (устранить на этапе 12).
- Координаты кластеров на карте группируются около центров районов.
- Прогноз по категориям не лучше простого среднего за 4 недели.
- Классификатор обучен на синтетических шаблонных текстах: на них точность 99%, на реальных обращениях она будет ниже. Порог уверенности по этим данным откалибровать нельзя; нужна небольшая ручная выборка текстов в реальном стиле.
- Файл модели категорий не хранится в git (`ml/models/`) и обучен на sklearn 1.5.2, а в окружении 1.9.1; перед публикацией модель нужно переобучить.
- Ограничение частоты запросов к публичному API хранится в памяти процесса и сбрасывается при перезапуске; за прокси нужно настроить определение адреса клиента (этап 12).
- Публичный номер обращения последовательный; по нему наружу отдаются только статус, тема и ответ, без текста и контактов.
- Фотографии лежат на диске в `backend/uploads/` и не входят в резервную копию базы (учесть на этапе 12).
- Внешний API принимает только текст и поля обращения, без фотографий; лимиты запросов по ключам хранятся в памяти процесса.
- Причина отклонения видна гражданину в кабинете: оператору нужно писать её с учётом этого.
- Граждане попадают в общий список пользователей администратора; для них нужен отдельный фильтр, в выборе роли роль «гражданин» лучше скрыть.
- Уведомления гражданину показываются только в кабинете, на почту не отправляются.
