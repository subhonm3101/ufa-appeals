# План экспериментов ВКР

Система анализа и приоритизации обращений граждан (город: Уфа).
Этот файл — рабочий документ: по ходу проекта в таблицы результатов вписываются реальные числа, а они потом переносятся в главу 4 записки.

## Общие правила

1. Каждый метод сравнивается с простым базовым методом. Вывод «модель хорошая» без базовой линии не засчитывается.
2. Параметры подбираются только на валидационной части. Итоговая метрика на тестовой части считается один раз.
3. Фиксируется `random_state`, версии библиотек и версия набора данных, чтобы эксперимент можно было повторить.
4. Если предложенный алгоритм не превзошёл базовые, результат всё равно описывается честно: где лучше, где нет, почему.
5. Каждый эксперимент сохраняет метрики в таблицу `ml_models.metrics` (JSONB) и в файл `results/<номер>.json`.
