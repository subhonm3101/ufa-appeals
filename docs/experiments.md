# План экспериментов ВКР

Система анализа и приоритизации обращений граждан (город: Уфа).
Этот файл — рабочий документ: по ходу проекта в таблицы результатов вписываются реальные числа, а они потом переносятся в главу 4 записки.

## Общие правила

1. Каждый метод сравнивается с простым базовым методом. Вывод «модель хорошая» без базовой линии не засчитывается.
2. Параметры подбираются только на валидационной части. Итоговая метрика на тестовой части считается один раз.
3. Фиксируется `random_state`, версии библиотек и версия набора данных, чтобы эксперимент можно было повторить.
4. Если предложенный алгоритм не превзошёл базовые, результат всё равно описывается честно: где лучше, где нет, почему.
5. Каждый эксперимент сохраняет метрики в таблицу `ml_models.metrics` (JSONB) и в файл `results/<номер>.json`.

## Э1. Классификация тем обращений

- **Гипотеза:** трансформерная модель даёт более высокий macro-F1, чем TF-IDF + Logistic Regression, особенно на невиданных подтемах.
- **Данные:** синтетический набор `data/appeals_synthetic.csv`, 5142 обращения, 7 категорий.
- **Модели:** TF-IDF + Logistic Regression; эмбеддинги `cointegrated/rubert-tiny2` + Logistic Regression.
- **Повторяемость:** 5 разбиений, seeds 2026–2030. Параметры подбирались на валидационной выборке.
- **Метрики ниже:** среднее значение ± стандартное отклонение по пяти разбиениям.

| Сценарий | TF-IDF macro-F1 | RuBERT-tiny2 macro-F1 | Разница (RuBERT − TF-IDF) | Победы RuBERT |
|---|---:|---:|---:|---:|
| A. Деление по `problem_id` | 0,972 ± 0,005 | 0,973 ± 0,004 | +0,001 ± 0,006 | 3 из 5 |
| B. Невиданные подтемы | 0,352 ± 0,084 | 0,438 ± 0,072 | +0,085 ± 0,042 | 5 из 5 |
| C. Случайное деление (утечка) | 0,971 ± 0,006 | 0,967 ± 0,004 | −0,005 ± 0,003 | 0 из 5 |

**Дополнительный результат одного разбиения, seed 2026:**

| Модель | Сценарий A: accuracy | Сценарий A: macro-F1 | Сценарий B: accuracy | Сценарий B: macro-F1 |
|---|---:|---:|---:|---:|
| TF-IDF + LogReg | 0,9739 | 0,9677 | 0,4490 | 0,3983 |
| RuBERT-tiny2 + LogReg | 0,9712 | 0,9679 | 0,5655 | 0,4682 |

- **Выводы:** на разбиениях по `problem_id` модели показали близкое качество: средняя разница macro-F1 составляет +0,001 в пользу RuBERT-tiny2 при стандартном отклонении разницы 0,006. На невиданных подтемах RuBERT-tiny2 превзошёл TF-IDF во всех пяти разбиениях; средняя разница macro-F1 составила +0,085. Однако абсолютное качество обеих моделей на новых подтемах остаётся ограниченным. В случайном сценарии с утечкой обе модели показывают высокие метрики, поэтому этот сценарий нельзя использовать как основную оценку способности обобщать на новые проблемы.

- **Ограничения эксперимента:** результаты получены на синтетических данных. Пять разбиений дают полезную оценку устойчивости, но не доказывают качество на реальных обращениях граждан. Для новых подтем необходимы контроль оператора и дальнейшая проверка на реальных размеченных данных.

- **Артефакты:** `ml/results/e1_tfidf_baseline.json`, `ml/results/e1_embedding_rubert.json`, `ml/results/e1_multiseed.json`, `ml/results/e1_table.md`.
